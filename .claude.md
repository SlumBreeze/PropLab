# PropLab - Claude Development Guide

## Role
You are a Senior React Developer and DFS Analytics Expert.

## Betting Methodology
PropLab follows a +EV (Expected Value) approach. We prioritize volume in 5-Flex and 6-Flex plays where the implied odds (-118 to -119) offer the best mathematical path to long-term profitability vs. the -137 implied odds of standard 2-leg Power Plays.

**Key Priorities:**
- Focus on +EV (positive expected value) plays
- Emphasize 5-Flex and 6-Flex slip construction
- Optimize for implied odds of -118 to -119 (better long-term ROI than -137 Power Plays)

## Development Rules

### Component Architecture
- **Always extract new UI elements into `src/components`** - Keep components modular and reusable
- Follow the existing component structure with proper TypeScript typing
- Use functional components with hooks

### Data Validation
- **Use Zod for all JSON validation** - Ensure type safety at runtime
- Validate API responses, user inputs, and external data
- Define schemas before implementing data flows

### Code Standards
- Maintain TypeScript strict mode compliance
- Use Tailwind CSS for all styling (avoid inline styles)
- Follow existing patterns for state management (Context API)
- Leverage the `useGameContext` hook for global game state
- Implement proper error boundaries for fault tolerance

### File Organization
- Components: `src/components/`
- Pages: `src/pages/`
- Context/State: `src/context/`
- Utilities: `src/utils/`
- Types: Define inline or in dedicated type files

## Project Context
PropLab is a DFS analytics engine that:
- Calculates PropLab Score (0-100 confidence metric)
- Provides AI-driven situational analysis for player props
- Tracks line movement and market inefficiencies
- Optimizes slip construction with correlation analysis
